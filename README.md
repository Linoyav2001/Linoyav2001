## Projects & Contributions

###  [Samsung Artifact Detection](https://github.com/Snafuzila/Samsung-Artifact-Detection)
**Deep Learning Image Quality Analysis (IQA) model, developed in collaboration with Samsung.**
*   **Overview:** A No-Reference IQA model designed to automatically detect, classify, and quantify image degradations (like sensor faults and processing errors) without needing a "clean" reference image.
*   **Methodology:** Utilizes normalization, artifact-specific augmentation, and CNN feature extraction to distinguish between high-quality captures and distorted ones.
*   **Tech Stack:** Python, Custom Convolutional Neural Networks (CNN), NumPy, and Pandas.


###  [EyesOn](https://github.com/afik191/EyesOn)
**AI-Powered Assistive Wearable for the Visually Impaired.**
*   **Overview:** A smart wearable system that helps visually impaired individuals navigate safely by detecting obstacles in real-time and providing directional audio feedback.
*   **Key Features:** Real-time object detection, live remote caregiver dashboard, two-way walkie-talkie audio, and self-healing connections.
*   **Tech Stack:** Raspberry Pi 5, Python, OpenCV, Ultralytics YOLOv11, React.js (Frontend), and WebSockets.


###  [Foodroid](https://github.com/Linoyav2001/Foodroid)
**A native Android application for discovering, saving, and managing recipes.**
*   **Overview:** Blends local user data management with external API integrations. Users can search for global recipes, upload custom ones, and securely store images in the cloud.
*   **Key Features:** User Authentication, External API Integration (TheMealDB), Custom Recipe Creation, and dynamic Shimmer UI loading effects. 
*   **Tech Stack:** Java, Single Activity Architecture, Retrofit2, Firebase (Realtime Database & Auth), Cloudinary API, and Material Design.


###  [Cost Manager App](https://github.com/Linoyav2001/Cost_Manager_App)
**A sophisticated, responsive personal finance tracker.**
*   **Overview:** Empowers users to take control of their financial health through intuitive expense logging, multi-currency support, and dynamic data visualization.
*   **Key Features:** Real-time expense tracking, advanced analytics via interactive SVG charts, comprehensive transaction logs, and real-time currency conversion logic.
*   **Tech Stack:** React 19 (Hooks), Material UI (MUI), Emotion (CSS-in-JS), Recharts, and Vite.


###  [Smart Traffic Light Management System](https://github.com/Linoyav2001/traffic-light-software-engineering)
**Software engineering and system architecture design for a smart traffic light simulator.**
*   **Overview:** An intelligent, real-time traffic management simulator designed to optimize intersection flow utilizing dynamic load analysis rather than static timers.
*   **Architecture:** Built on Object-Oriented principles and statecharts to manage complex phase transitions. Validation is driven by Behavior-Driven Development (BDD).
*   **Tools:** BDD with Gherkin Syntax (Cucumber), Object-Oriented Design (OOD), app.diagrams, and Mermaidchart.
